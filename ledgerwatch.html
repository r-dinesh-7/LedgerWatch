Technical architecture

How raw network and blockchain records are reduced to a small set of explainable investigative leads.

Data reduction funnelexample run
Design notes
INGESTION
Chunked readers stream CSV/JSON/XML through DuckDB and Polars — the full file is never materialized in memory, enabling multi-million-row datasets on commodity hardware.
FEATURE ENGINE
Behavioral, temporal, network and graph features are computed per entity and stored in Parquet for columnar re-use across models.
INTELLIGENCE ENGINE
Anomaly ensembles, clustering and graph analytics feed a prioritization layer that outputs ranked, explainable leads only.
